# Choose where bots work

Open **Settings**, then select **Sandbox**.

**Local** uses the computer that runs your Akeru server. It needs no key.

You can connect these cloud providers with your own account:

- E2B
- Daytona
- Vercel Sandbox
- Upstash Box

Vercel Sandbox needs a token, team ID, and project ID. Akeru stores provider keys on your Akeru server. It does not write them to projects or sandbox files.

Select **Make default** to use a connected provider for every bot. Disconnecting the default provider changes the default back to Local.

Akeru keeps auto-idle on so an unused sandbox can pause.
